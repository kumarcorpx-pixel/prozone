7. Daily Operations Guide

Adding a New Client

Admin → Clients (sidebar) → Create User → Fill: Name, Email, Phone, Password → Role: Client → Create

Adding PRO Staff

Admin → Clients (sidebar) → Create User → Fill: Name, Email, Phone, Password → Role: PRO Staff → Create

Processing a Service Request

1. Admin → Requests → View new request
2. Assign to staff (auto or manual dropdown)
3. Staff logs in → sees request → updates status
4. Staff uploads documents, adds timeline notes
5. Staff marks "Completed"
6. Admin → Invoicing → Create invoice → Send to client
7. Record payment when received

Tracking Expiring Documents

Admin → Expiry Calendar → Filter by status/type → Take action before expiry → Sync to Google Calendar (optional)

Generating Reports

Admin → Reports → Select type (Revenue/Service/Client/Staff) → View charts & tables → Export CSV
