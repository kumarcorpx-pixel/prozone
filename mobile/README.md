# CorporatePRO Mobile App

iOS & Android app for YABS Public Relations Management - corporatepro.cloud

## Tech Stack
- **Framework**: React + Vite + Capacitor 6
- **Platform**: iOS (Capacitor native bridge)
- **API**: corporatepro.cloud/api/v1/* (JWT Bearer auth)
- **Auth**: JWT with refresh token (24h grace period)
- **Storage**: Capacitor Preferences (encrypted on iOS)

## Setup

### Prerequisites
- Node.js 18+
- Mac with Xcode 15+ (for iOS build)
- Apple Developer Account ($99/year)

### Development
```bash
cd mobile
npm install
npm run dev          # Opens Vite dev server at localhost:5173
```

### iOS Build
```bash
npm run build        # Build web assets
npx cap add ios      # First time only — creates ios/ folder
npx cap sync ios     # Copy web assets to native project
npx cap open ios     # Opens Xcode
```

Then in Xcode: select your team, set bundle ID, and run on simulator or device.

### Android Build
```bash
npx cap add android
npx cap sync android
npx cap open android # Opens Android Studio
```

## API Endpoints Used

| Method | Endpoint | Description |
|--------|----------|-------------|
| POST | /api/auth/login | Login (returns JWT + user) |
| POST | /api/auth/refresh | Refresh expired token (24h grace) |
| GET | /api/v1/companies | Paginated company list |
| GET | /api/v1/employees | Paginated employee list |
| GET | /api/v1/documents | Paginated document list |
| GET | /api/v1/requests | Paginated service requests |

All v1 endpoints return: `{ success, data, meta: { page, limit, total, totalPages } }`

## Auth Flow
1. User enters email/password on login screen
2. App calls POST /api/auth/login
3. JWT token stored in Capacitor Preferences (encrypted on iOS)
4. All subsequent API calls include `Authorization: Bearer <token>`
5. On 401 response, app calls POST /api/auth/refresh
6. If refresh fails (>24h expired), user redirected to login

## App Store Submission
1. Build in Xcode with Release configuration
2. Archive → Distribute App → App Store Connect
3. Upload to TestFlight for beta testing
4. Submit for App Store Review (1-3 business days)
