## 3. STEP-BY-STEP BUILD INSTRUCTIONS

### Prerequisites
- Mac with **Xcode 15+** (download from Mac App Store)
- **Apple Developer Account** ($99/year) — https://developer.apple.com/enroll
- **Node.js 18+** — https://nodejs.org
- iPhone for real device testing (optional but recommended)

### Step 1: Clone & Install
```bash
# On your Mac
git clone https://github.com/kumarcorpx-pixel/prozone.git
cd prozone/mobile
npm install
```

### Step 2: Build Web Assets
```bash
npm run build
```
This creates the `dist/` folder with production-optimized HTML/CSS/JS.

### Step 3: Add iOS Platform (first time only)
```bash
npx cap add ios
```

### Step 4: Sync Web Assets to Native
```bash
npx cap sync ios
```

### Step 5: Generate App Icons
Create a **1024x1024 PNG** icon:
- Navy background (#0f2340)
- Gold "Y" letter or YABS logo centered
- No transparency, no rounded corners

Then run:
```bash
chmod +x scripts/generate-icons.sh
./scripts/generate-icons.sh /path/to/your-icon-1024.png
```

### Step 6: Open in Xcode
```bash
npx cap open ios
```

### Step 7: Configure Xcode Project
1. Click the **"App"** target in the left sidebar
2. **General** tab:
   - Display Name: `CorporatePRO`
   - Bundle Identifier: `cloud.corporatepro.app`
   - Version: `1.0.0`
   - Build: `1`
   - Deployment Target: `16.0`
3. **Signing & Capabilities** tab:
   - Check "Automatically manage signing"
   - Select your Team (Apple Developer account)
4. **Info** tab:
   - App Transport Security: Already allows HTTPS (default)
   - No additional permissions needed (no camera/location used)

### Step 8: Test on Simulator
1. Select **iPhone 15 Pro** from the device dropdown
2. Press **Cmd+R** to build and run
3. Test each screen:
   - Login with real credentials
   - Dashboard loads stats
   - Companies list scrolls and paginates
   - Search works with debounce
   - Back navigation works
   - Logout clears session

### Step 9: Test on Real Device
1. Connect iPhone via USB cable
2. Trust the computer on the iPhone
3. Select your iPhone from the device dropdown
4. Press **Cmd+R**
5. Verify:
   - Safe area (notch/dynamic island) handled
   - Tab bar doesn't overlap home indicator
   - Keyboard pushes content up
   - Scrolling is smooth (60fps)
   - Touch targets are comfortable (44px+)

### Step 10: Archive for App Store
1. Select **"Any iOS Device (arm64)"** as build target
2. Menu: **Product → Archive**
3. Wait for archive (1-3 minutes)
4. Xcode opens the **Organizer** window
5. Click **"Distribute App"**
6. Select **"App Store Connect"**
7. Click **"Upload"**
8. Wait for processing (5-10 minutes)
